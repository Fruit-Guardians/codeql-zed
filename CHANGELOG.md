# Changelog

## 0.1.1 (unreleased)

- Add Linux and Windows CI coverage with pinned CodeQL CLI versions.
- Add qlpack, minimum-version, malformed-query, path, and native LSP smoke checks.
- Improve missing-binary, invalid-path, and invalid-argument errors.
- Keep the extension focused on CodeQL language support and the official CLI
  language server.

## 0.1.0

- Add CodeQL and QL Tree-sitter language support for `.ql` and `.qll` files.
- Start the CodeQL CLI language server from Zed's LSP integration.
- Support PATH discovery, an explicit binary path, complete argument overrides,
  and environment overrides.

The official `zed-industries/extensions` pull request is intentionally not
submitted yet.
