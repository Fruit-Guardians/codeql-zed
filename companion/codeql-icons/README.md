# CodeQL Icons

This is an optional companion icon theme for the CodeQL language extension.
It maps `.ql` and `.qll` files to the CodeQL-inspired mark in this directory.

Zed language extensions do not currently expose a per-language logo field. To
keep the main language extension focused, the icon theme is kept separate.

Install this directory as a second dev extension, then select `CodeQL Icons`
from Zed's icon theme selector. The mark is an original CodeQL-inspired design;
it is not an official GitHub or CodeQL logo.
